## Quick Start

**1. Clone the repository**

```bash
git clone https://github.com/rajashekhar1242/Java_Learning.git
```

**2. Navigate to the project**

```bash
cd Java_Learning
```

**3. Compile a Java program**

```bash
javac Main.java
```

**4. Run the program**

```bash
java Main
```

*Make sure Java JDK is installed and configured on your system.*
